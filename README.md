# Helix Nebula (SDSS-V DR19) – LVM-DAP Analysis and Plotting Tools

This repository contains all scripts and Jupyter notebooks used to generate
the figures included in the manuscript *main.pdf*, which presents a spectroscopic
analysis of the Helix Nebula (NGC 7293) using SDSS-V Local Volume Mapper (LVM) data.

The codebase is centered around two main analysis notebooks:

---

## 📘 Main Notebooks

### **1. `plot_DAP_Helix_cor.ipynb`**
This is the **primary notebook** used to generate **all emission-line, flux,
kinematic, radial-profile, and diagnostic maps** included in the manuscript.

It performs the following tasks:

- Loads the LVM-DAP dataproducts for the Helix Nebula.
- Generates:
  - flux maps,
  - velocity and dispersion maps,
  - auroral-line maps,
  - ionization-structure figures,
  - radial profiles of fluxes and line ratios,
  - comparisons with literature values.
- Applies custom colormaps defined in `cmaps_CLC.py`.
- Utilizes utility functions in `my_utils.py`.
- Produces all figures in the manuscript **except those derived from HIPS data**.

This notebook is therefore the **working backbone** of the entire analysis workflow.

---

### **2. `hips_plot.ipynb`**
This notebook is dedicated exclusively to generating the **HIPS-based background
images** included in the manuscript.

It:

- Downloads or accesses HiPS projections,
- Produces wide-field views of the Helix Nebula,
- Applies coordinate overlays and color adjustments,
- Outputs the large-scale optical/Hα composite background used in the paper.

These figures complement those generated by the DAP but rely on external HiPS servers.

---

## 📁 Supporting Scripts

### **`my_utils.py`**
Collection of helper functions used by the plotting notebooks.  
Includes routines for:

- Loading and manipulating DAP cubes,
- Interpolation and masking,
- Custom figure formatting,
- Map normalization.

### **`cmapCLC.py` / `cmaps_CLC.py`**
Python modules defining the **custom colormaps** adopted in the manuscript figures.
They include:

- Diverging maps,
- Ionization-sensitive palettes,
- High-dynamic-range options for auroral lines.

These colormaps ensure a consistent visualization style across all figures.

### **`Plot_PDF_from_DAP.ipynb`**
Notebook that loads the stellar population PDFs derived by the LVM-DAP
and produces:

- 2D probability density diagrams,
- log(g)–Teff and [Fe/H]–Teff distributions,
- comparisons with the MaStar stellar library.

Used specifically for the PDF figure included in the manuscript.

### **`Plot_PDF_from_coeffs.ipynb`**
Utility notebook used to validate the PDF-generation routines and produce
diagnostic plots based on coefficient sampling.
